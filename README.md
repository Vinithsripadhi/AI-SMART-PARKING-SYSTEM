# 🚗 AI Smart Parking System

An intelligent parking management system developed using **Python, Flask, SQLite, HTML, CSS, and JavaScript**. The system helps manage vehicle entry, parking slots, vehicle records, search functionality, and parking fee calculation through a simple web-based interface.

---

## 📌 Project Overview

The **AI Smart Parking System** is designed to solve real-world parking management problems by providing an automated platform to monitor parking slots and maintain vehicle information.

The system allows users to:
- Register incoming vehicles
- Assign available parking slots
- Track vehicle entry and exit details
- Calculate parking charges
- Search vehicle records
- Monitor parking availability through a dashboard

The project is developed with future AI integration possibilities such as **vehicle detection, number plate recognition, and automated slot detection using Computer Vision**.

---

# 🎯 Problem Statement

Traditional parking systems require manual monitoring of vehicles and parking spaces, which can lead to:

- Time-consuming vehicle tracking
- Difficulty managing available slots
- Manual record maintenance
- Errors in parking fee calculation
- Poor parking space utilization

This project provides a digital solution for efficient parking management.

# ✨ Features

## 🚘 Vehicle Management
- Add new vehicle details
- Store owner information
- Record entry and exit time
- Track vehicle status

## 🅿️ Parking Slot Management
- Display available parking slots
- Assign slots to vehicles
- Update slot availability after vehicle exit

## 🔍 Vehicle Search
- Search vehicles using vehicle number
- View complete vehicle details
- Check parking history

## 💰 Parking Fee Calculation
- Automatic parking duration calculation
- Hour-based parking fee calculation
- Maintains parking payment records

## 📊 Dashboard
- Total parking slots
- Available slots
- Occupied slots
- Real-time parking status display
